# 환경

배경과 주변광, 대기 산란, 바람 등 3D 공간의 사실적인 환경 요소를 구성하는 방법을 다룹니다.

## 학습 주제

1. **[SkyBox](./skybox.md)** : 씬의 배경을 360도 큐브맵 텍스처로 채워 무한한 공간감을 표현
2. **[IBL](./ibl.md)** : 주변 환경 이미지를 분석하여 물체에 사실적인 반사와 전역 조명 적용
3. **[SkyAtmosphere](./skyatmosphere.md)** : 실시간 물리 기반 대기 산란을 통한 동적 하늘과 노을 시뮬레이션
4. **[WindManager](./wind.md)** : 전역 바람 방향과 풍속을 제어하여 식생·수면에 자연스러운 움직임 부여
