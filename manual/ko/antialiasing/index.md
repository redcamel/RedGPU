# 안티앨리어싱

**안티앨리어싱**(Antialiasing) 은 3D 렌더링 시 발생하는 픽셀 계단 현상 (Aliasing)을 완화하는 기법입니다. RedGPU는 시간축 누적 기반의 `TAA`, 하드웨어 멀티샘플링 기반의
`MSAA`, 후처리 필터 기반의 `FXAA` 를 지원하며 `redGPUContext.antialiasingManager` 에서 통합 제어합니다.

## 1. 배타적 동작 및 자동 선택

안티앨리어싱 기법은 한 번에 하나만 활성화할 수 있으며, 새로운 기법을 켜면 기존 설정은 자동으로 해제됩니다. 엔진 초기화 시 디스플레이의 `devicePixelRatio` 에 따라 기본 기법이 자동 선택됩니다.

- **고해상도 디스플레이** (`devicePixelRatio > 1.0`): **TAA** 기본 활성화
- **일반 디스플레이** (`devicePixelRatio <= 1.0`): **MSAA** 기본 활성화

```javascript
const manager = redGPUContext.antialiasingManager;
console.log(`TAA: ${manager.useTAA}, MSAA: ${manager.useMSAA}, FXAA: ${manager.useFXAA}`);
```

## 2. 기법별 비교

렌더링 품질과 성능 목표에 맞는 기법을 선택합니다.

| 기법                  | 방식            | 품질 및 특징                                                                                                                       | 성능 비용 | 권장 환경                           |
|:----------------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------|:----------|:------------------------------------|
| **[TAA](./taa.md)**   | 시간축 누적     | **최상** — 모션 벡터로 잔상을 억제하고 지오메트리 외곽선과 셰이더·텍스처 알리어싱을 모두 해결 (`devicePixelRatio > 1.0` 에서 최적) | 중간      | 고품질 데스크톱 및 고해상도 웹 환경 |
| **[MSAA](./msaa.md)** | 하드웨어 샘플링 | **우수** — G-Buffer 멀티샘플링으로 지오메트리 외곽선을 선명하게 처리 (셰이더 내부 알리어싱은 미지원)                               | 매우 높음 | 기하학적 외곽선이 중요한 단순한 씬  |
| **[FXAA](./fxaa.md)** | 후처리 필터     | **보통** — 추가 버퍼 없이 화면 전체 경계를 빠르게 부드럽게 처리 (미세한 텍스처 블러 발생 가능)                                     | 매우 낮음 | 모바일 및 저사양 기기               |
