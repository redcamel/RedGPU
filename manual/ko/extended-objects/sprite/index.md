# 스프라이트

RedGPU는 3D 공간과 2D 화면에서 2D 이미지를 효과적으로 활용할 수 있는 **Sprite** 시스템을 제공합니다. 항상 카메라를 향하는 **빌보드**(Billboard) 기능과 프레임 애니메이션을 지원하는
스프라이트 시트 기능을 통해 씬에 생동감을 불어넣을 수 있습니다.

## 1. 주요 특징

- **빌보드**(Billboard) 지원 : 3D 공간에 배치되지만 항상 카메라를 정면으로 바라보도록 설정할 수 있어 UI, 파티클, 아이콘 등에 최적화되어 있습니다.
- **3D 및 2D 뷰 완벽 대응**: `View3D` 공간에 배치하는 `Sprite3D`/`SpriteSheet3D`와 픽셀 좌표계 기반의 `View2D` 화면에 배치하는 `Sprite2D`/
  `SpriteSheet2D`를 모두 지원합니다.
- **애니메이션 시스템**: 하나의 텍스처에 여러 프레임이 포함된 시트를 사용하여 고성능 스프라이트 애니메이션을 구현할 수 있습니다.
- **자동 종횡비 조절**: 텍스처의 크기에 맞춰 스프라이트의 렌더링 비율이 자동으로 조정됩니다.

## 2. 주요 구성 요소

| 클래스명              | 네임스페이스     | 설명                                                                                        |
|:----------------------|:-----------------|:--------------------------------------------------------------------------------------------|
| **`Sprite3D`**        | `RedGPU.Display` | 3D 공간에서 단일 이미지를 사용하는 빌보드 스프라이트 객체입니다.                            |
| **`SpriteSheet3D`**   | `RedGPU.Display` | 3D 공간에서 프레임 애니메이션을 지원하는 스프라이트 시트 객체입니다.                        |
| **`Sprite2D`**        | `RedGPU.Display` | `View2D` 환경에서 픽셀 단위로 배치되는 2D 스프라이트 객체입니다.                            |
| **`SpriteSheet2D`**   | `RedGPU.Display` | `View2D` 환경에서 프레임 애니메이션을 재생하는 2D 스프라이트 시트 객체입니다.               |
| **`SpriteSheetInfo`** | `RedGPU.Display` | 스프라이트 시트의 구조(가로·세로 세그먼트, 프레임 수, FPS 등)를 정의하는 데이터 객체입니다. |
