# 기본 객체

3D 공간을 시각적으로 구성하는 기본 디스플레이 객체인 `Mesh`, 계층 구조인 **씬 그래프**(Scene Graph), 그리고 표면 이미지를 매핑하는 `Texture` 를 다룹니다.

---

## 학습 로드맵

1. **[Mesh](./mesh.md)** : 지오메트리 (`Geometry`)와 머티리얼 (`Material`)을 결합하여 3D 물체를 생성하고 공간 변환을 제어하는 방법
2. **[Scene Graph](./scene-graph.md)** : `Group3D` 및 부모-자식 계층 구조를 설계하고 트랜스폼 상속을 활용하는 방법
3. **[Texture](./texture.md)** : 일반 비트맵, `.ktx2` GPU 압축 텍스처 및 `TextureArray` 를 로드하여 재질에 적용하는 방법
