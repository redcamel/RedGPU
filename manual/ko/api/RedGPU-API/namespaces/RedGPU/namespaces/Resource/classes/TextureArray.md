# Class: TextureArray

Defined in: [src/resources/texture/TextureArray.ts:31](https://github.com/redcamel/RedGPU/blob/26caeb42c00946af874ef1905798dd18e81e18de/src/resources/texture/TextureArray.ts#L31)

여러 이미지를 레이어별로 업로드하여 `texture_2d_array` GPU 텍스처를 생성합니다.

모든 레이어는 첫 번째 이미지 크기로 리사이즈되며, 동일한 소스 목록은 캐시된 인스턴스를 재사용합니다.

***

### Example
```typescript
const textureArray = new RedGPU.Resource.TextureArray(
    redGPUContext,
    ['layer0.png', 'layer1.png', 'layer2.png'],
    true,
    (texture) => console.log(texture.width, texture.height)
);
```
