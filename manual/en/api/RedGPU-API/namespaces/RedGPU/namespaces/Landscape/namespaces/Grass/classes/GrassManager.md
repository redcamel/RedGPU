# Class: GrassManager

Defined in: [src/landscape/grass/GrassManager.ts:37](https://github.com/redcamel/RedGPU/blob/26caeb42c00946af874ef1905798dd18e81e18de/src/landscape/grass/GrassManager.ts#L37)

Class that manages large-scale grass scattering, camera-centered GPU instance baking, GPU frustum culling, and rendering on a `Landscape`.

::: warning
This class is automatically created by the system.<br/>Do not create an instance directly using the 'new' keyword.
:::

***

### Example
```typescript
// Register a new grass type via the landscape grass manager
const grass = landscape.grassManager.addType({
    name: 'MeadowGrass',
    mesh: grassMesh,
    densityPerHectare: 50000,
    cullingDistance: 80
});
```
