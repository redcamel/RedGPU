# Class: InstancingMesh

Defined in: [src/display/instancingMesh/InstancingMesh.ts:72](https://github.com/redcamel/RedGPU/blob/1e59941e5b6c61327f4eb8821e5e6784da4a52cb/src/display/instancingMesh/InstancingMesh.ts#L72)

GPU instancing mesh class that renders multiple meshes sharing a single geometry and material in a single draw call.

Each instance (`InstancingMeshObject3D`) has independent position, rotation, scale, and `opacity`, supporting GPU compute shader-based frustum culling and Level of Detail (LOD).

***

### Example
```typescript
const instancingMesh = new RedGPU.Display.InstancingMesh(redGPUContext, 1000, 100, geometry, material);
scene.addChild(instancingMesh);
```
