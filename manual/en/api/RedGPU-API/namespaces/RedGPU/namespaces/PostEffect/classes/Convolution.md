# Class: Convolution

Defined in: [src/postEffect/effects/convolution/Convolution.ts:49](https://github.com/redcamel/RedGPU/blob/1e59941e5b6c61327f4eb8821e5e6784da4a52cb/src/postEffect/effects/convolution/Convolution.ts#L49)

Post-processing effect that combines pixels with surrounding pixels using a 3x3 convolution kernel.

***

### Example
```typescript
const effect = new RedGPU.PostEffect.Convolution(redGPUContext);
effect.kernel = RedGPU.PostEffect.Convolution.SHARPEN;
view.postEffectManager.addEffect(effect);
```
