# Class: BRDFGenerator

Defined in: [src/resources/texture/ibl/core/brdf/BRDFGenerator.ts:27](https://github.com/redcamel/RedGPU/blob/1e59941e5b6c61327f4eb8821e5e6784da4a52cb/src/resources/texture/ibl/core/brdf/BRDFGenerator.ts#L27)

Class that generates a 2D BRDF LUT (Look-Up Table) texture for the Split Sum Approximation.

The LUT is rendered only once in `rg16float` format at 128x128 on first access, and is created automatically by the system.

::: warning
This class is automatically created by the system.<br/>Do not create an instance directly using the 'new' keyword.
:::

***

### Example
```typescript
// Correct access method
const brdfGenerator = redGPUContext.resourceManager.brdfGenerator;
```

## See

[BRDF LUT test example](https://redcamel.github.io/RedGPU/examples/3d/skybox/ibl/brdfLutTest/)
