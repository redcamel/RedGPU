# Class: PackedTexture

Defined in: [src/resources/texture/packedTexture/PackedTexture.ts:43](https://github.com/redcamel/RedGPU/blob/26caeb42c00946af874ef1905798dd18e81e18de/src/resources/texture/packedTexture/PackedTexture.ts#L43)

Packs channels from multiple source textures into a single `rgba8unorm` texture.

Results with the same source/mapping combination are cached in `PackedTextureManager` and shared via reference counting.

***

### Example
```typescript
const packed = new RedGPU.Resource.PackedTexture(redGPUContext);
await packed.packing({
  r: texture1.gpuTexture,
  g: texture2.gpuTexture
}, 512, 512);
```

### packing()

> **packing**(`textures`, `width`, `height`, `label?`, `componentMapping?`, `commandEncoder?`): `Promise`\<`void`\>

Defined in: [src/resources/texture/packedTexture/PackedTexture.ts:114](https://github.com/redcamel/RedGPU/blob/26caeb42c00946af874ef1905798dd18e81e18de/src/resources/texture/packedTexture/PackedTexture.ts#L114)

Creates a packed texture by combining channels of the source textures.

Does nothing if all sources are empty, and reuses the cache if the same combination already exists.

#### Example
```typescript
await packed.packing(
  {r: aoTexture.gpuTexture, g: roughnessTexture.gpuTexture, b: metallicTexture.gpuTexture},
  1024, 1024, 'ORM_TEXTURE'
);
```

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `textures` | \{ `a?`: `GPUTexture`; `b?`: `GPUTexture`; `g?`: `GPUTexture`; `r?`: `GPUTexture`; \} | Source GPUTexture map per channel (r/g/b/a) |
| `textures.a?` | `GPUTexture` | - |
| `textures.b?` | `GPUTexture` | - |
| `textures.g?` | `GPUTexture` | - |
| `textures.r?` | `GPUTexture` | - |
| `width` | `number` | Resulting texture width |
| `height` | `number` | Resulting texture height |
| `label?` | `string` | Resulting texture label (optional) |
| `componentMapping?` | [`ComponentMapping`](../type-aliases/ComponentMapping.md) | Channel mapping info (optional) |
| `commandEncoder?` | `GPUCommandEncoder` | External command encoder (optional; if omitted, an internal encoder is created and submitted immediately) |
